# Cordada V2

The front end of Cordada, rebuilt from the single-file proposal in `web/orb/premium.html` as a
Next.js app. The whole Sherpas analysis is one mountain route: the intro builds the mountain and
draws the route, Cordi rises from behind the summit and comes down to base camp, and the whole
mountain stays in view with a short summary beside every flag. Pick any flag (Cordi walks there
and the detail opens) or follow the guided tour, camp by camp.

```bash
cd MCPV2
npm install
npm run dev        # http://localhost:3100
```

- `?case=<id>` opens a family directly (`daniel-emily-johnson`, `michael-carter`,
  `samantha-lewis`, `timothy-melanie-weah`).
- `npm run data` re-imports the cases and the voice/sfx manifests from `web/orb`
  (generated by the backend's `npm run cases:orb`, `voice:orb` and `sfx:orb`).

## How it is built

```
app/                    layout (fonts), page, globals.css (tokens and all styles)
src/Experience.tsx      start screen, top bar, the expedition
src/expedition/         the climb: world.ts (mountain and route geometry), render.ts (canvas
                        painter), steps.ts (camps from the case), Expedition.tsx (camera, Cordi,
                        intro, overview, guided tour), Detail.tsx (the panel), Narration.tsx
src/dashboard/scenes/   one interactive scene per topic, shown in the detail panel
src/orb/                Cordi: emotions, soft-body physics (engine.ts), DOM (Orb.tsx), effects
src/stage/              the speech bubble and the ask panel
src/data/               case data and voice manifests (JSON) with types
src/lib/                audio, copy (Spanish labels, number format), tiny store
```

The mountain is painted on a canvas, whole, every frame (no SVG layers to repaint piece by
piece, which flickered). Cordi lives in world units on its own spring, so the camera can move
freely around it; the orb engine gives its body weight (jelly, stretch, pendulum, lagging face).
Every figure comes from the case data.
